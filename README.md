# Mini-Project---Customer-Shopping-Trends-

This project explores a customer shopping trends dataset to uncover customer behavior, 
popular product categories, and purchasing patterns.
The raw data was sourced from Kaggle and thoroughly cleaned, formatted, and prepared using Microsoft Excel.

Data Preparation done via power query
checked for missing and null values.
Standardized text formats, casing, and column headers.
Checked for duplicates and ensured data consistency across all fields.

Mini-Project-Customer Shopping Trends
Customer Shopping Trends report, multi-page interactive Power BI report,
designed to analyze customer shopping habitrs, transactional behavior, regional sales, and product performances

Page 1: Sales Overview
KPIs: Total Customers (3.9K), Total Revenue ($233.08K), Total Orders (4K), Average order value ($59.76).   
Visuals: sales by Category waterfall chart, Sales by Season  chart, location Sales Details matrix table.   

page 2: Customer Analytics
KPIs: Total Customers (3.9K), Average Age (44.7), Average Rating (3.75), Average order value ($59.76).   
Visuals: Purchase distribution by Age Group, Gender pie chart,  Age & gender Category ,average rating satisfaction matrix table.

Page 3: Shopping Insights
KPIs: Total Orders (4K), Total Revenue ($233.08K), average order value ($59.76), Average Rating (3.75).   
Visuals: Purchase Frequency column chart, Customer Location map, Payment Method rankings, and Shipping Type pie chart.
